# OVT — One Verse Tool

성경 한 구절과 짧은 묵상글로 **1080 × 1080 묵상 이미지**를 만들고, 블로그(워드프레스)와 페이스북·인스타그램에 올리는 도구입니다.
블로그 「하루에 말씀 한 절」(인스타그램 @oneverse_a_day)을 매일 운영하기 위해 만들었습니다.

> 사용 방법은 **[사용설명서](사용설명서.md)** 를 보세요.

## 할 수 있는 일

- **성경 구절 불러오기** — 권·장·절을 고르면 말씀 레이어에 본문이 들어갑니다. 끝 절을 고르면 여러 절을 범위로 넣습니다.
- **생명의 삶 달력** — 두란노 「생명의 삶」 날짜별 본문 달력. 날짜를 누르고 절을 누르면 말씀과 날짜가 함께 바뀝니다. **QT본문 추가** 버튼으로 새 달 본문을 게시판에서 가져옵니다.
- **이미지 편집** — 배경 사진(확대·이동·밝기·대비·채도·오버레이), 말씀·묵상글 글꼴 28종과 크기·색·정렬·줄간격·너비·그림자·외곽선, 되돌리기/다시 실행, 스타일 프리셋 저장.
- **내보내기** — 이미지를 PNG로 저장(저장 폴더 지정 가능).
- **발행** — 이미지를 워드프레스에 올리면 지정한 날짜 오전 7시에 블로그·페이스북·인스타그램에 예약 게시됩니다. 발행 전에 중복 날짜·날짜 형식·인스타 글자 수(2,200자)를 검사하고, 최근 게시 상태와 실패 시 **다시 시도** 버튼을 보여줍니다.
- **게시글 텍스트** — 날짜·말씀·묵상글·해시태그를 따로 적고 한 번에 복사합니다.
- **자동 저장** — 작업 내용은 브라우저와 서버에 저장되어, 다른 기기에서도 이어서 작업할 수 있습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 도구 본체. 파일 하나에 화면·스타일·스크립트가 모두 들어 있습니다(빌드 과정 없음). |
| `qt-2026.json` | 생명의 삶 날짜별 본문 달력 데이터 |
| `qt-update.php` | **QT본문 추가** 버튼이 호출하는 서버 스크립트. 두란노 게시판의 새 달 본문을 읽어 달력에 추가 |
| `tools/make-qt.sh` | 같은 작업을 터미널에서 하는 도구 (`--list`로 게시판 확인) |
| `img/` | 로고·아이콘 등 이미지 |
| `bible.json` | 성경 본문 데이터. **저작권이 있어 이 저장소에는 올리지 않습니다**(`.gitignore`). 서버와 로컬에만 있습니다. |

그 밖에 서버 쪽에는 워드프레스 플러그인(`ovt-bridge`)과 중계 스크립트(`api.php`)가 있어 이미지 발행, 예약 게시, 작업 저장, 게시 상태 확인을 맡습니다. 이 저장소에는 포함되어 있지 않습니다.

## 실행 환경

- 웹 브라우저에서 열어 쓰는 단일 페이지입니다. 서버 로그인(Apache 기본 인증)으로 보호되어 있어 **본인만** 사용합니다.
- 발행·저장·QT본문 추가는 PHP가 돌아가는 호스팅과 워드프레스가 있어야 동작합니다. 이미지 만들기와 내보내기만 쓴다면 `index.html`과 `bible.json`이 같은 폴더에 있으면 됩니다.
- 이미지 크기는 1080 × 1080px 고정입니다.
- 글자 줄바꿈은 크롬과 사파리에서 같게 보이도록 측정 방식을 맞춰 두었습니다.

## 저장소 관련

- 공개 저장소이므로 비밀번호·토큰·서버 접속 정보는 넣지 않습니다.
- 성경 본문(`bible.json`)과 로컬 백업(`backups/`)은 저장소에 없습니다.
